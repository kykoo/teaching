Acceleration Response

import numpy as np
import matplotlib.pyplot as plt
from scipy.signal import welch

# Parameters
fs = 200.0  # Hz sampling
nyq = fs/2
T = 600.0   # seconds
dt = 1/fs
fn = np.array([1.0, 3.0, 5.0])  # Hz
zeta = 0.01
wn = 2*np.pi*fn

# Time and excitation
t = np.arange(0, T, dt)
N = len(t)
np.random.seed(0)
force = np.random.randn(len(fn), N)  # modal forces

# Newmark-beta (average acceleration) for each mode
beta = 1/4
gamma = 1/2
m = 1.0
acc_modes = np.zeros((len(fn), N))

for idx, wni in enumerate(wn):
    k = (wni**2) * m
    c = 2*zeta*wni*m
    x = np.zeros(N)
    v = np.zeros(N)
    a = np.zeros(N)
    # Newmark constants
    a0 = m/(beta*dt**2)
    a1 = m/(beta*dt)
    a2 = m*(1/(2*beta)-1)
    a3 = c*gamma/(beta*dt)
    a4 = c*(gamma/beta - 1)
    a5 = c*dt*(gamma/(2*beta)-1)
    k_eff = k + a0 + a3
    for n in range(1, N):
        p_eff = force[idx, n] + a0*x[n-1] + a1*v[n-1] + a2*a[n-1] + a3*x[n-1] + a4*v[n-1] + a5*a[n-1]
        x[n] = p_eff / k_eff
        v[n] = gamma/(beta*dt)*(x[n]-x[n-1]) + (1 - gamma/beta)*v[n-1] + dt*(1 - gamma/(2*beta))*a[n-1]
        a[n] = (x[n]-x[n-1])/(beta*dt**2) - v[n-1]/(beta*dt) - (1/(2*beta)-1)*a[n-1]
    acc_modes[idx] = a

# Sum modal accelerations and add 7 Hz sinusoidal noise and a slow drift component
acc = acc_modes.sum(axis=0)
acc_n = acc + 3*np.sin(2*np.pi*7*t)            # stronger 7 Hz component
acc_n += 30*np.sin(2*np.pi*0.01*t)       # very low-frequency drift (0.005 Hz)

# PSD
f, Pxx_i = welch(acc, fs=fs, window='hann', nperseg=2**13, noverlap=2048, scaling='density')
f, Pxx_n = welch(acc_n, fs=fs, window='hann', nperseg=2**13, noverlap=2048, scaling='density')

plt.figure(figsize=(8,6))
plt.subplot(2,1, 1)
plt.plot(t, acc/1000, label='ideal')
plt.plot(t, acc_n/1000, label='noisy')
plt.xlim(0, 60)
plt.xlabel('Time (sec)')
plt.ylabel('acc (g)')
plt.title('3DOF System: Acc Response under random excitation')
plt.grid(True, which='both', ls='--', alpha=0.6)
plt.legend()
plt.subplot(2,1, 2)
plt.semilogy(f, Pxx_i/1e6, label='ideal')
plt.semilogy(f, Pxx_n/1e6, label='noisy')
plt.xlim(0, 20)
plt.xlabel('Frequency (Hz)')
plt.ylabel('PSD (g^2/Hz)')
plt.grid(True, which='both', ls='--', alpha=0.6)
plt.legend()
plt.tight_layout()
plt.show()

Motivation

It would be ideal to have filters for modifying frequency contents of a given signal.

  • Low-pass filters are for noise-removal on a higher-frequency band or anti-aliasing
  • High-pass filters are for noise removal on a lower-frequency band
  • Band-pass filters are for isolating a peak for further analysis
  • Notch filters are for removing electricity noises
  • Ideal filters never exists, requiring future inputs and infinite input records. this is call non-causual.
  • There are causual, i.e., existing and achievable, filters that we are going to discuss.

Digital vs Analog Filters

Analogue Filter - Physical hardware consisting of R, C, Op-amp, etc

Digital Filter

  • Software algorithm performed on a series of sampled data \(y(t_k)\)
  • some DAQ systems use analogue filters for anti-aliasing purpose.

Linear Time-Invariant System (LTI)

For an arbitrary \(x(t)\)

\[ y(t) = \int_{-\infty}^{t} h(t-\tau) x(\tau) d\tau \]

\[ Y(i\omega) = H(i\omega) X(i\omega) \]

where \(h(t) \to H(i\omega)\), \(x(t) \to X(i\omega)\), and \(y(t) \to Y(i\omega)\) are F.T. pairs.

Linear Time-Invariant System (LTI)

  • Every LTI system acts as a filter, i.e., input sinal is filtered through LTI Systems resuilting modification of the original input signal \(x(t)\)

\[ H(i\omega) = \lvert H(i\omega)\rvert e^{i \angle H(i\omega)} \]

  • Filters are characterised by their amplitude & phases.

What a Digital Filter do

\[ \begin{aligned} Y(i\omega) &= H(i\omega) X(i\omega) \\ &= |H(i\omega)|e^{i\angle H(i\omega)} |X(i\omega)| e^{i\angle X(i\omega)} \\ &= |H(i\omega)||X(i\omega)| e^{i(\angle H(i\omega)+\angle X(i\omega))} \end{aligned} \]

\[ |Y| = |H||X| \\ \angle Y = \angle H + \angle X \]

Filter Performance Index

\[ |Y| = |H||X| \\ \angle Y = \angle H + \angle X \]

  • \(|H|\) needs to be close to the brickwall filter (ideal fitler), and
  • \(\angle H\) needs to be as small as possible, as it distorts time history

Filter Structure (General)

\[a_1 y(n) = b_1 x(n) + b_2 x(n-1) + \cdots + b_{n_b+1} x(n-n_b) \\ - a_2 y(n-1) - \cdots - a_{n_a+1} y(n-n_a)\]

Equivalently, \[a_1 y(n) = \sum_{k=0}^{n_b} b_{k+1}\,x(n-k) - \sum_{k=1}^{n_a} a_{k+1}\,y(n-k)\]

Transfer function: \[H(z) = \frac{Y(z)}{X(z)} = \frac{\sum_{k=0}^{n_b} b_{k+1} z^{-k}}{a_1 + \sum_{k=1}^{n_a} a_{k+1} z^{-k}}\]

FIR Filter (Finite Impulse Response)

  • No feedback: set \(a_1=1\) and \(a_{k>1}=0\).
  • Difference equation reduces to \[y(n) = \sum_{k=0}^{n_b} b_{k+1}\,x(n-k)\]
  • Transfer function: \[H_{\text{FIR}}(z) = \sum_{k=0}^{n_b} b_{k+1} z^{-k}\]
  • Properties: always BIBO stable; can be linear-phase if \(b_k\) are symmetric/anti-symmetric; group delay \((n_b/2)\) (for linear phase).

IIR Filter (Infinite Impulse Response)

  • Feedback present: \(a_{k>1} \neq 0\).
  • Difference equation: \[y(n) = \frac{1}{a_1}\Big[\sum_{k=0}^{n_b} b_{k+1}\,x(n-k) - \sum_{k=1}^{n_a} a_{k+1}\,y(n-k)\Big]\]
  • Transfer function: \[H_{ ext{IIR}}(z) = \frac{\sum_{k=0}^{n_b} b_{k+1} z^{-k}}{a_1 + \sum_{k=1}^{n_a} a_{k+1} z^{-k}}\]
  • Properties: recursive, potentially infinite-length response; efficient sharp transitions; stability requires poles inside unit circle; phase generally nonlinear.

Commonly Used Filters

Filter Type Ripple/Flatness Transition Steepness Phase/Delay Notes for DAQ/SHM
Butterworth IIR Flat passband, monotonic Moderate Nonlinear (smooth) Good general-purpose; predictable roll-off
Cheby I IIR Passband ripple (set by ε) Steeper than Butter. Nonlinear When passband ripple is acceptable and sharper cut needed; watch ripple in amplitude metrics.
Elliptic IIR Ripple in both bands; zeros Steepest for order Nonlinear Minimum order for given specs; good for tight anti-aliasing constraints.
FIR (Kaiser) FIR Window sets sidelobes Depends on taps Linear phase (symmetric) Stable; choose β/taps for ripple vs transition; zero-phase offline with filtfilt.

def gen_amp_phase_resp():
    import numpy as np
    import matplotlib.pyplot as plt
    from scipy.signal import butter, cheby1, ellip, firwin, freqz, sosfreqz

    fs = 200.0
    nyq = fs/2
    cutoff = 0.5*nyq  # normalized 0.5 of Nyquist
    orders = [2, 4, 6]
    rp = 1      # dB passband ripple for Cheby1/Ellip
    rs = 40     # dB stop attenuation for Ellip

    filters = [
        ('Butterworth', lambda n: butter(n, cutoff, fs=fs, btype='low', output='sos'), 'iir'),
        ('Chebyshev I', lambda n: cheby1(n, rp, cutoff, fs=fs, btype='low', output='sos'), 'iir'),
        ('Elliptic',    lambda n: ellip(n, rp, rs, cutoff, fs=fs, btype='low', output='sos'), 'iir'),
        ('FIR (Kaiser)', None, 'fir'),
    ]

    fir_taps = [41, 81, 161]
    fir_beta = 8.6  # ~60 dB sidelobes

    # Magnitude figure
    fig_mag, axes_mag = plt.subplots(2, 2, figsize=(12, 6), sharex='col')
    # Phase figure
    fig_phase, axes_phase = plt.subplots(2, 2, figsize=(12, 6), sharex='col')

    for idx, (name, maker, ftype) in enumerate(filters):
        r = idx // 2
        c = idx % 2
        axm = axes_mag[r, c]
        axp = axes_phase[r, c]
        if ftype == 'iir':
            for n in orders:
                sos = maker(n)
                w, H = sosfreqz(sos, worN=1024, fs=fs)
                axm.plot(w/nyq, 20*np.log10(np.maximum(np.abs(H), 1e-6)), label=f'order {n}')
                axp.plot(w/nyq, np.unwrap(np.angle(H)), label=f'order {n}')
        else:
            for taps in fir_taps:
                h = firwin(taps, cutoff/nyq, window=('kaiser', fir_beta))
                w, H = freqz(h, worN=1024)
                axm.plot(w/np.pi, 20*np.log10(np.maximum(np.abs(H), 1e-6)), label=f'{taps}-tap')
                axp.plot(w/np.pi, np.unwrap(np.angle(H)), label=f'{taps}-tap')
        axm.axvline(cutoff/nyq, color='k', ls='--', alpha=0.7)
        axm.set_title(f'{name} magnitude')
        axm.set_ylabel('Mag (dB)')
        axm.set_ylim(-60, 5)
        axm.grid(True, which='both', ls='--', alpha=0.6)
        axm.text(cutoff/nyq, -30, ' fc ', ha='right', va='top', fontsize=9, color='k')

        axp.axvline(cutoff/nyq, color='k', ls='--', alpha=0.7)
        axp.set_title(f'{name} phase')
        axp.set_xlabel('Normalized freq (× Nyquist)')
        axp.set_ylabel('Phase (rad)')
        axp.set_yticks(-np.pi*np.arange(0,4))
        axp.set_yticklabels([f"{-k}π" if k>0 else "0" for k in range(0,4)])
        axp.grid(True, which='both', ls='--', alpha=0.6)
        
        axm.legend(loc='lower left')
        axp.legend(loc='lower left')

    fig_mag.tight_layout()
    fig_phase.tight_layout()
    plt.show()

    fig_mag.savefig('signalprocess/filters-mag.png')
    fig_phase.savefig('signalprocess/filters-phase.png')

def gen_amp_phase_resp_bpf():
    import numpy as np
    import matplotlib.pyplot as plt
    from scipy.signal import butter, cheby1, ellip, firwin, freqz, sosfreqz

    fs = 200.0
    nyq = fs/2

    filters = [

        ('Chebyshev I', lambda n: cheby1(n, rp, band, fs=fs, btype='bandpass', output='sos'), 'iir'),

    fir_beta = 8.6  # ~60 dB sidelobes

    # Magnitude figure
    fig_mag, axes_mag = plt.subplots(2, 2, figsize=(12, 6), sharex='col')

    fig_phase, axes_phase = plt.subplots(2, 2, figsize=(12, 6), sharex='col')

    for idx, (name, maker, ftype) in enumerate(filters):
        r = idx // 2
        c = idx % 2

        if ftype == 'iir':

    fig_mag.savefig('signalprocess/filters-bpf-mag.png')
    fig_phase.savefig('signalprocess/filters-bpf-phase.png')

    wsn = ws/nyq
    # 1 dB passband ripple, 80 dB stopband attenuation
    rp = 1
    rs = 40

    # PSDs
    f, Pxx = welch(acc_orig, fs=fs, window='hann', nperseg=4096, noverlap=2048, scaling='density')
    f2, Pyy = welch(acc_filt, fs=fs, window='hann', nperseg=4096, noverlap=2048, scaling='density')

Summary

  • Low-pass, High-pass, and Band-pass filters can be used manipulate frequency contents of a given time history
  • Low-pass filters are used for anti-aliasing and decimation
  • High-pass fitlers are used for removing low-frequency drift in signal
  • Band-pass filters are used for isolate a frequency content for further analysis
