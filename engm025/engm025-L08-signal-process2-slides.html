BAT Echolocalisation

Spectrogram (STFT)

  • Spectrogram is the squared magnitude of the short-time Fourier transform (STFT).
  • It uses a sliding window: good time resolution for short windows, good frequency resolution for long windows.
  • Common in acoustics, vibration, and machine monitoring.

BAT Echolocalisation

Wavelet Analysis

  • Represents the signal using scaled and shifted wavelets (localized in time).
  • Multi-resolution: good time resolution at high frequencies, good frequency resolution at low frequencies.
  • Useful for transients, impacts, and rapidly changing dynamics.

Motivation

It would be ideal to have filters for modifying frequency contents of a given signal.

  • Low-pass filters are for noise-removal on a higher-frequency band or anti-aliasing
  • High-pass filters are for noise removal on a lower-frequency band
  • Band-pass filters are for isolating a peak for further analysis
  • Notch filters are for removing electricity noises
  • Ideal filters never exists, requiring future inputs and infinite input records. this is call non-causual.
  • There are causual, i.e., existing and achievable, filters that we are going to discuss.

Digital vs Analog Filters

Analogue Filter - Physical hardware consisting of R, C, Op-amp, etc

Digital Filter

  • Software algorithm performed on a series of sampled data \(y(t_k)\)
  • some DAQ systems use analogue filters for anti-aliasing purpose.

Linear Time-Invariant System (LTI)

For an arbitrary \(x(t)\)

\[ y(t) = \int_{-\infty}^{t} h(t-\tau) x(\tau) d\tau \]

\[ Y(i\omega) = H(i\omega) X(i\omega) \]

where \(h(t) \to H(i\omega)\), \(x(t) \to X(i\omega)\), and \(y(t) \to Y(i\omega)\) are F.T. pairs.

Linear Time-Invariant System (LTI)

  • Every LTI system acts as a filter, i.e., input sinal is filtered through LTI Systems resuilting modification of the original input signal \(x(t)\)

\[ H(i\omega) = \lvert H(i\omega)\rvert e^{i \angle H(i\omega)} \]

  • Filters are characterised by their amplitude & phases.

What a Digital Filter do

\[ \begin{aligned} Y(i\omega) &= H(i\omega) X(i\omega) \\ &= |H(i\omega)|e^{i\angle H(i\omega)} |X(i\omega)| e^{i\angle X(i\omega)} \\ &= |H(i\omega)||X(i\omega)| e^{i(\angle H(i\omega)+\angle X(i\omega))} \end{aligned} \]

\[ |Y| = |H||X| \\ \angle Y = \angle H + \angle X \]

Filter Performance Index

\[ |Y| = |H||X| \\ \angle Y = \angle H + \angle X \]

  • \(|H|\) needs to be close to the brickwall filter (ideal fitler), and
  • \(\angle H\) needs to be as small as possible, as it distorts time history

Filter Structure (General)

\[a_1 y(n) = b_1 x(n) + b_2 x(n-1) + \cdots + b_{n_b+1} x(n-n_b) \\ - a_2 y(n-1) - \cdots - a_{n_a+1} y(n-n_a)\]

Equivalently, \[a_1 y(n) = \sum_{k=0}^{n_b} b_{k+1}\,x(n-k) - \sum_{k=1}^{n_a} a_{k+1}\,y(n-k)\]

Transfer function: \[H(z) = \frac{Y(z)}{X(z)} = \frac{\sum_{k=0}^{n_b} b_{k+1} z^{-k}}{a_1 + \sum_{k=1}^{n_a} a_{k+1} z^{-k}}\]

FIR Filter (Finite Impulse Response)

  • No feedback: set \(a_1=1\) and \(a_{k>1}=0\).
  • Difference equation reduces to \[y(n) = \sum_{k=0}^{n_b} b_{k+1}\,x(n-k)\]
  • Transfer function: \[H_{\text{FIR}}(z) = \sum_{k=0}^{n_b} b_{k+1} z^{-k}\]
  • Properties: finite length response; always BIBO stable; can be linear-phase.

IIR Filter (Infinite Impulse Response)

  • Feedback present: \(a_{k>1} \neq 0\).
  • Difference equation: \[y(n) = \frac{1}{a_1}\Big[\sum_{k=0}^{n_b} b_{k+1}\,x(n-k) - \sum_{k=1}^{n_a} a_{k+1}\,y(n-k)\Big]\]
  • Transfer function: \[H_{ ext{IIR}}(z) = \frac{\sum_{k=0}^{n_b} b_{k+1} z^{-k}}{a_1 + \sum_{k=1}^{n_a} a_{k+1} z^{-k}}\]
  • Properties: recursive, potentially infinite-length response; efficient sharp transitions; potentially unstable ; phase generally nonlinear.

Summary

  • Low-pass, High-pass, and Band-pass filters can be used manipulate frequency contents of a given time history
  • Low-pass filters are used for anti-aliasing and decimation
  • High-pass fitlers are used for removing low-frequency drift in signal
  • Band-pass filters are used for isolate a frequency content for further analysis
  • Hand-on exercises will be provided in the Tutorial Session
