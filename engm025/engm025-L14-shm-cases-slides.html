    • VHF Digital Radio
  • 700 MHz Clearance Project

700 MHz Clearance Project for HGMs

The 700 MHz Clearance Project moved broadcast TV services out of the 694–790 MHz band so that spectrum could be reused for mobile broadband/5G.

For HGMs, this usually involved:

  • Antenna and feeder upgrades/reconfiguration at height.
  • Temporary works and staged installation planning to keep services live during upgrades.
  • Structural reassessment, because antenna changes can alter wind loading and dynamic response.

Tuned Liquid Damper

  • Engineering Consultant COWI assessed MyP
  • Predicted response was close to the limit, and additional damping was recommended.
  • Two TLD units installed
    • aiming for 4% damping or higher at 0.575 Hz
    • Total Mass of damper 1.2 tonnes

SHM on MyP

  • Conventional approach (i.e. signal cables wired to a DAQ unit) was rejected due to RF interference
  • DAQ needs to be done at each sensor (i.e. distributed decentralised DAQ)
  • GPS based time-synchronisation used: *Ki Young Koo et al (2019) “Time Synchronisation for Wireless Sensors Using Low-Cost GPS Module and Arduino”, Frontiers in Built Environment
  • 110V main power is provided by Arqiva
  • Fibre-optic Ethernet Network used for data communication
  • Base Station @ Ground
    • Internet connection by 3G/4G Router
    • Raspberry Pi to upload to the sftp server at Exeter

Closure

  • A lots of measured data are there for your analysis all over the world : ) Well-trained data-processing-capable peoples are rare in the world.

  • When designing a SHM system, how to prcess data needs to be designed together. A small set of carefully chosen sensors with a clear data-processing plan is ideal

  • SHM will be used more widely with technological advances of IT, IoT, EE, Drone, etc.
